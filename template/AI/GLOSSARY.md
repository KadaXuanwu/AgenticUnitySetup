# Glossary

The game terms, one meaning each (CLAUDE.md, Response Style). In STE these are the "technical nouns" and "technical
verbs". Use the term in the left column. Do not use the words in "Not" for this meaning. The GDD has the full rules;
this file gives only what each word means.

A new term goes here in the same pass that brings it in. If a word has two meanings, give one of them a new term and
write the change here.
